Build the MVP of "Food Finders" in this folder: one plain HTML page listing today's free-food events at Stony Brook, updated daily from a public calendar feed. Keep it as small as possible.

Files to create:
- build.mjs: Node 22 script with no npm dependencies
- index.html: generated by build.mjs
- .github/workflows/update.yml: GitHub Actions job that runs the script daily
- README.md: short setup and run instructions

Data source (public, no login):
https://sbengaged.stonybrook.edu/ical/stonybrook/ical_stonybrook.ics
It redirects, so follow redirects. Do not log in or scrape any other SBEngaged page.

How the feed is formatted:
- It is iCalendar text with about 8,000 BEGIN:VEVENT ... END:VEVENT blocks.
- Handle CRLF line endings. A line starting with a space or tab continues the previous line.
- Properties can have parameters, such as SUMMARY;ENCODING=QUOTED-PRINTABLE:Event name, so match both NAME: and NAME;...:
- Free-food events have a line starting with CATEGORIES that contains the exact text "Free Food & Refreshments". The tag can be one of several comma-separated values on that line, and events have several CATEGORIES lines, so check all of them with a substring match.
- DTSTART and DTEND are UTC, formatted like 20261109T170000Z.
- Use SUMMARY for the name, LOCATION for the place, URL for the event link, and CN="..." on the ORGANIZER line for the host. Trim the host name.
- Unescape \, \; and \\ in text values.
- Remove a trailing ", United States" from LOCATION.
- Many events have LOCATION "Sign in to download the location". Treat that as no location.

Which events to include:
- Use today's date in America/New_York, never the UTC date.
- Include an event if it runs at any point today in New York time, comparing its New York start date and end date with today.
- Sort by start time.

index.html requirements:
- Plain semantic HTML only: no CSS, no style attributes, no JavaScript, no images, no external resources.
- Title and h1: Food Finders
- Below that, a line such as "Free food for Monday, November 9".
- Then a ul with one li per event, in this format: start time in New York time, event name as a link to its URL, location, host.
- If an event has no location, show a link reading "Location on SBEngaged" that goes to the event URL.
- If there are no events, show "No free food listed today."
- At the bottom, show "Last updated" with the date and time in New York time, and "Listed from events tagged Free Food & Refreshments on SBEngaged."
- HTML-escape all text from the feed.

Failure handling:
If the download fails or the response contains no BEGIN:VEVENT, exit with an error and do not overwrite the existing index.html.

GitHub Actions:
- Run on schedule with cron "17 11 * * *" and also allow workflow_dispatch.
- Grant contents: write.
- Check out the repo, set up Node 22, run node build.mjs, and commit and push index.html only if it changed.
